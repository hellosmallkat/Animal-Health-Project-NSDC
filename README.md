
#  Animal Health Classification Project

**Machine Learning Project for Wildlife Conservation**

Welcome! 
This project focuses on **predicting the health condition of animals** to aid in wildlife conservation. Using machine learning, the goal is to classify whether an animal is in danger or at risk of dying based on five key symptoms. By leveraging data-driven insights, this project contributes to **animal welfare, biodiversity protection, and ecosystem management**.

##  About This Project

Wildlife conservation requires timely identification of at-risk animals. In this project, we build a **predictive model** using the **Random Forest Classifier** and other machine learning techniques to assess the danger level of various species — from birds to mammals — based on symptoms such as:

* Fever
* Coughing
* Weight loss
* Pain
* And more

The project involves **data cleaning, handling imbalanced datasets, exploratory data analysis (EDA), and model evaluation** to ensure accurate predictions.


##  Dataset

**Animal Condition Classification Dataset (Kaggle)**

The dataset contains:

* Multiple animal species
* Symptoms include fever, coughing, pain, and weight loss
* Labels indicating whether the animal is in danger

### Tools & Libraries

##  Project Milestones

### Milestone 1: Import Libraries & Load Dataset

* Set up the Python environment
* Load and inspect the dataset

### Milestone 2: Exploratory Data Analysis (EDA)

* Visualize symptom distribution
* Identify patterns in danger levels

### Milestone 3: Data Cleaning & Preprocessing

* Handle missing values
* Format features for modeling

### Milestone 4: Address Imbalanced Dataset

* Apply Random Over-Sampling to balance classes

### Milestone 5: Model Training – Random Forest Classifier

* Train and tune a Random Forest model
* Generate predictions for animal danger classification

### Milestone 6: Comparing Machine Learning Models

* Train additional models for comparison
* Identify the best-performing algorithm

### Milestone 7: Model Evaluation

* Evaluate models using accuracy, precision, recall, and F1-score
* Interpret results to inform conservation decisions
